# Templates

Drop the current-semester report template here (DOCX) and it becomes the base for
`deliverables/BinGenie_Sem_Report.docx`.

Expected filename pattern: `Sem_Template.docx` (rename once supplied).

What the build takes from the template:

- page size, margins and section structure
- heading styles and numbering scheme
- front matter order (title page, bonafide certificate, acknowledgement, abstract,
  table of contents, list of figures, list of tables, abbreviations)
- footer / page-numbering convention
- any mandatory declarations (plagiarism, AI-use)

What the build does **not** take from the template: content. All content comes from
`src/build_spec.py`, which follows the chapter map in Section 10 of
`deliverables/BinGenie_What_We_Can_Use.docx`.
