# Backend

## 📚 Java Backend Development — Interactive Course Notes

[`java-backend-course/`](java-backend-course/) contains an interactive website with
**PowerPoint-style slide decks and detailed notes for all 24 sessions** of the
*Java Backend Development Course With IBM Certification* syllabus (GeeksforGeeks brochure):

- 4 module decks · 24 sessions · 402 content slides with detailed notes
- theory + practice for every brochure topic: diagrams, 278 code blocks (138 runnable Java
  programs compiled and run, 134 with verified output), 24 hands-on labs, 244 quiz questions, flashcards
- **FAANG-level interview track**: 40 deep dives, 25 timed coding rounds (11 Hard) with verified
  solutions, 13 system-design rounds (HLD + LLD), 240 interview Q&As graded SDE-1/SDE-2/Senior,
  mock interviews, 23 DSA patterns and behavioral prep (`#/interview`)
- projects: Splitwise backend, Splitwise with Cursor AI agents, Airbnb microservices backend
- syllabus coverage map, search, presenter mode, print-to-PDF, and `.pptx` downloads with speaker notes
- code targets Java 21 · Spring Boot 4.1 · Spring Cloud 2025.1 · MySQL 8.4 · Redis 7 · Kafka 4 (KRaft)

Open `java-backend-course/index.html` in a browser, or run
`python3 -m http.server 8000` inside that folder. See the
[course README](java-backend-course/README.md) for details.

> Independent study material based on the public course brochure; not an official
> GeeksforGeeks or IBM publication.
